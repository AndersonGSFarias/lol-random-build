# 🎮 LOL Build Generator

Uma aplicação web que gera builds aleatórias para **League of Legends**, permitindo aos jogadores explorarem novas combinações de campeões, runas, feitiços e itens de forma dinâmica e divertida.

---

## 🚧 Status do Projeto

> ⚠️ Este projeto ainda está em desenvolvimento.

Novas funcionalidades e melhorias visuais estão sendo implementadas continuamente.

---

## 📄 Sobre o Projeto

O objetivo da aplicação é criar uma experiência interativa onde o usuário pode gerar uma composição completa com apenas um clique. A proposta combina aleatoriedade com regras inteligentes, garantindo builds coerentes e jogáveis.

Os dados utilizados são obtidos através do **Data Dragon**, serviço oficial da Riot para dados estáticos do jogo.

---

## 🚀 Funcionalidades

- 🎲 Geração aleatória de builds
- 🧙 Seleção de campeão
- ⚔️ Itens aleatórios
- 🔮 Runas primárias e secundárias
- ✨ Feitiços baseados em regras (ex: smite para jungle)
